# 交付驗證

本文件記錄 Windows Steam App 2212790／build 24231082 的繁中插件驗證範圍。翻譯發生於文字繪製與尺寸量測期間；遊戲的英文資料、識別碼及存檔值維持原樣。

| 要求 | 證據 | 狀態 |

| 外掛載入，不改原遊戲資產 | BepInEx x86 載入；177項原始 data 檔案 SHA-256 對照 | 通過，最終核對一致 |
| 不改玩家存檔 | game0.xml SHA-256 與測試前備份一致；診斷未載入遊戲進度 | 通過，最終核對一致 |
| 繁中介面與敘事 | 4237筆詞庫鍵；主線、社群事件、自然筆記及介面人工翻譯；catalog/progress.json | 已建立 |
| 避免把識別碼當文字翻譯 | 未替換 scene／managed 用途分類，及138筆已替換內容中的拉丁字母判定 | 已完成已擷取語料審核 |
| 動態數值、富文字與未知內容 | test-catalog.ps1：114項正反例 | 通過 |

| 可停用、卸載及安全更新 | 設定開關、已擁有檔案雜湊檢查；修改檔保留與失敗回復測試 | 通過既有安裝器測試 |

「翻譯後不同」不等於完整翻譯率。未翻譯的內部路徑、識別碼、平台名稱、玩家帳號、學名及教學原文已依用途保留。原遊戲任意未來版本、第三方插件組合及所有可能遊戲進度並未窮舉驗證；相容範圍以上述確切版本為準。


## 0.1.1 效能回歸

114 項詞庫測試通過。預算排版快取經 720p／1080p、一般／易讀四種設定量測，交付 DLL 再檢查 720p 兩模式的 421 個故事版型（812／813 個長文字欄位），新增溢出均為 0。報紙中英切換的 10 個翻譯欄位驗證來源、尺寸與字型還原。基準測試僅載入存檔副本；玩家原存檔另以測試前 SHA-256 核對。完整效能結果見 PERFORMANCE.zh-TW.md。

## 0.1.2 表單重疊修正

修正 s-0012 自願證人陳述表，以及 s-0028、s-0081、c-0005、mu0001 同類警察報告。原文首行空格原用於讓開獨立標籤；中文正文改為從下一行開始。涵蓋 15 個來源變體、14 個詞庫鍵，並同步修改 manual 翻譯來源與安裝詞庫。

驗證包含 114 項詞庫案例、15 項表單分行案例、原生遊戲修正前後截圖、正文文末與中英切換檢查，以及 720p／1080p 的一般／易讀模式故事長文稽核。詳細紀錄：overlap-fix/verification.json。先前效能快取保留，更新的排版結果亦合併至內嵌快取。

## 0.1.3 固定橫線邊界

先前檢查只考慮文字框、原文高度及捲動範圍，未限制表單內固定分隔線。現在警察報告正文以其下方最近的 Thin Wing Lines 上緣為硬邊界，保留 8 個版面單位；不沿用英文可溢出的高度。結果快取另加版本標記，避免取用舊排版。9 個長文欄位按此嚴格條件驗證；完整 421 個故事亦檢查 720p／1080p、一般／易讀模式。驗證紀錄見 form-border-fix/verification.json。

## 0.1.4 短句回歸

修正 0.1.3 遺漏少於 100 字來源的正文問題。表單正文全部納入高度限制、快取失效與原生版型稽核（12 欄，含 3 個短句）。只有單行空間的摘要使用量測後的全形空格避開獨立標籤；保留原文、斜體及中英切換。新增回歸檢查要求 s-0028 的 SNAFU 短句以單行縮排呈現，並檢查 F8 還原內容、字型與欄位尺寸。720p／1080p、一般／易讀模式的紀錄見 short-form-fix/verification.json。

## 0.1.5 問卷與儲存退出

問卷 s-0104 回答與題目分開顯示，年齡標籤量測後縮至數字欄之前。421 個故事在 720p／1080p、一般／易讀模式的長文稽核皆無新增溢出；最終版另以原生截圖檢查年齡標籤及文末。

透過存檔副本和原生 GamePowerButton.Click 量測舊漢化、移除漢化 DLL、兩輪優化版。每輪完整保留按鈕與退出回呼的兩次存檔；輸出 XML 可解析，玩家原存檔與 177 個原檔雜湊一致。暫時探針已移出安裝目錄。詳細時序、剩餘 Unity 清理問題與限制見 EXIT-PERFORMANCE.zh-TW.md；機器可讀結果見 exit-form-fix/verification.json。

## 0.1.6 尋人啟事

以原生 s-0056 的相鄰欄位起點距離為界，Info、Description、Finding Info 分別可用 49、129、22 版面單位。720p／1080p、一般／易讀四種設定量測皆保留至少 2 單位間距；實際高度與存檔 SHA-256 見 missing-poster-fix/verification.json。同步修改人工翻譯來源與安裝詞庫，原本的退出及效能修正保留。

## 0.1.7 便箋正文與長人名

s-0023 的正文使用紙張可見底部留白界線（自正文起點 700 單位），不再沿用英文溢出高度。名牌依內側寬度量測為單行，保留完整人名與身分文字。以原生預覽在 720p／1080p、一般／易讀模式檢查正文末行與長人名，並確認 F8 英文／中文切換恢復、存檔及 177 個遊戲原檔不變。詳細量測見 note-name-fix/verification.json。

## 0.1.8 主選單

720p／1080p、一般／易讀模式下的 6 個標題欄位全部符合寬高界線，標題與陰影尺寸一致。F8 切換確認原始文字、字級、幾何保持不變，恢復中文後量測一致。存檔及 177 個遊戲原檔雜湊未改變。詳見 menu-title-fix/verification.json。

## 0.1.9 人物介面

720p／1080p、一般／易讀模式的原生人物技能視窗及選人按鈕預覽通過欄寬、行高檢查；另檢查 Young Alvin、Old Buzz 與三／四位數技能等級。F8 切換後原始字串、字級和幾何不變。RZ5 名稱對照由原版 CharacterPeriodDatabase 的建構資料確認，117 個詞庫案例包含譯名統一與跨行表頭。存檔及 177 個原檔保持不變。詳見 character-ui-fix/verification.json 及 name-evidence.json；預覽未載入玩家進度。

## 0.1.13 紙張頁面與退出崩潰

修正 s-0065 等將紙張圖片掛在 Page 頁面本身的版型：以圖片按比例繪製後的實際底邊限制正文，保留頁腳留白，不再讓文字落入兩頁間的空隙。s-0065 的兩個正文欄位在 720p／1080p、一般／易讀四組設定都在紙張界線內，英文切換保留原始字串與幾何。

修正隨載入器附帶的 MonoMod.Utils.dll 對此 Unity x86 Mono 的相容性：SetMonoCorlibInternal 原本寫入位移 79，破壞位移 76 的 friend_assembly_names 指標；本機匹配的官方 PDB 確認 corlib_internal 應位於 83。這是退出時 mono_domain_free+0x480 讀取 0x01000000 的原因。修正版不修改遊戲 DLL、Mono DLL 或存檔，也不跳過原生退出／存檔流程。

一般預覽退出及存檔副本的原生儲存退出均回傳 0，無 Crash!!! 記錄；兩次退出存檔都完成，副本 XML 可解析，玩家原存檔 SHA-256 不變。ComputeBuffer 退出警告仍可出現，已證實不是此次存取違規的原因；試驗性 GPU 清理已移除。詳見 page-paper-fix/verification.json 與 exit-crash-fix/verification.json。

相容性修正限定於此套件驗證的 Mono SHA-256：473D59FE1F1A2CBBF37340517CA6F9C6A48330D44DC609E5C3209ADF63792FCF。安裝器會拒絕其他 Mono 版本；遊戲更新後請重新驗證。MonoMod 原檔、修補腳本與授權皆保留。

119 個詞庫案例通過，包含正數、零及負數 EXP REMAINING，統一顯示「剩餘 XX 經驗」。年代及劇情未改動。詳細結果見 illustration-exp-fix/verification.json。
