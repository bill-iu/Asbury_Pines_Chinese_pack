# 0.1.12 全量資訊圖排版檢查

適用 Steam build 24231082、Windows 系統微軟正黑體。檢查完整 421 個原生故事／社群資訊圖，而非僅限目前解鎖項目。未載入玩家存檔或呼叫解鎖事件。

## 修正

- 所有繁中故事文字使用適合中文的最低行距及自動換行，避免原版手寫字型的緊縮行距造成同一段落內疊字。
- 短標題、日期及標籤也納入量測；長正文依原文排版空間與既有硬邊界縮放，保留先前警察表格、便箋、姓名牌等修正。
- 補回日誌與信件必要的標題留白，整理紀念牌名單、尋人啟事標題、塗鴉、留言、報紙日期及招募廣告。
- 教材的詞語、釋義及上標編號合併排列；報紙註腳編號隨正文移動；詩稿旁註回到對應句子。
- 鬥坑告示以四組時間、罪行及對戰資料逐項呈現，保留全部姓名與內容。
- 考古日誌日期欄只顯示日期；原本誤塞入日期欄的重複正文仍完整保留在正文欄。
- 研究信件的圖片留白獨立計算，不再被後續整段縮放壓回圖片位置。

原始盤點為 2,922 個欄位；其中 20 個獨立註腳／上標數字改為隨文字排列，中文模式停用原本固定位置的重複數字。F8 切回英文可還原。

使用 Unity 原生文字生成器量測字形範圍，排除刻意的陰影／浮雕複本、捲動遮罩外的固定按鈕及空白字元的空白圖集區塊。另逐張查看疑似問題版型及捲動末端，並複查教材段落的實際行距。

長正文檢查涵蓋每種設定的 815／816 個欄位。一般模式沒有新增高度溢出；易讀模式只有研究信件 s-0267 的預留圖片空間比英文多一行，因此超過原文高度比較值。實際捲動到底確認全文末句留在背景內、仍有底部留白，並確認正文不壓到圖片標籤。此項為已人工核對的量測例外，不把它當成未修復的裁切問題。

原始英文、原生欄位尺寸與字級保持不變；英文切換還原檢查、詞庫測試及警察表格測試另記錄於 `full-layout-audit`。177 個原版遊戲檔案與玩家存檔雜湊保持一致。

排版結果與模板都有快取，封裝預載 3,052 筆正文量測及 4 組插圖排版；正常遊玩不執行批次掃描。診斷命令於交付前關閉。

本次覆蓋目前遊戲內的全部靜態故事資訊圖及上述顯示設定，不代表已窮舉其他字型、解析度或未來版本的動態內容。
