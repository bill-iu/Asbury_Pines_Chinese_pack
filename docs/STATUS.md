# Asbury Pines 繁體中文插件 0.1.14

適用 Windows Steam build 24231082（遊戲顯示 `[EA] 3.01.001`）。這是外掛式顯示翻譯：使用 BepInEx x86 與系統繁中文字型，不覆寫遊戲程式、資源包或存檔。

目前詞庫共 4,237 個正規化來源鍵，包含 3,317 筆人工整理條目。已完成主線故事、社群事件、自然筆記、介面、角色與資源、加成和通知等已擷取可見內容的翻譯及動態模板處理。未替換字串及已翻譯內容中保留的拉丁字母已完成用途審核；品牌、帳號、內部代碼、虛構月份、學名與語言教學範例依用途保留。這些數字是詞庫統計，不是把所有內部字串當成翻譯完成率。

排版支援中文量測、通知框寬、速度／資源提示框寬高、故事固定欄位字級調整、報紙首字母裝飾、名冊欄位及插圖留白。已在 1280×720 與 1920×1080 檢查代表性介面和故事，並批次量測 421 個故事版型的長文字欄位；一般及易讀模式皆檢查文字框和可捲動範圍。詳細結果見 RELEASE-VERIFICATION.md。

F8 可在本次遊戲期間切換繁中／英文；F9 重新載入詞庫。永久停用、重新啟用、安裝與卸載指令見 README.zh-TW.md。診斷功能預設關閉，正常遊玩不需開啟。

遊戲更新後，若程式雜湊不符，插件會保留英文並停止掛鉤。安裝器不覆蓋未經辨認或自行修改的既有檔案；卸載只移除安裝清單中雜湊仍相符的檔案。請使用完整 ZIP 封裝，保留其中的授權文件與來源碼。

本版本驗證涵蓋上述確切遊戲版本與所列版型，未窮舉所有遊戲進度、字型及第三方插件組合。若遇到漏譯或排版問題，請提供故事／介面名稱、解析度及截圖，便可針對該顯示情境修正。


0.1.1 已移除載入時的全場景文字掃描，加入可見文字延後處理、繪製快取與背景讀取的預算排版快取。六個故事切換總計由 348.2 毫秒降至 262.8 毫秒，英文基準 254.3 毫秒。完整比較與殘餘差異見 PERFORMANCE.zh-TW.md。

0.1.2 修正自願證人陳述表與同類警察報告的標籤／正文重疊：原文以首行空格避開獨立標籤，譯文改為保留標籤行、正文從下一行開始。涵蓋 15 個來源變體（14 個詞庫鍵），不增加執行期掃描。

0.1.3 修正警察報告正文穿過固定橫線：依下一條表格線限制可用高度並保留 8 個版面單位間距，必要時微調中文字級。橫線查找結果與排版結果均快取，不掃描整個場景。

0.1.4 補上表單短句排版。取消表格邊界檢查的 100 字門檻；只有一行空間的摘要改為依獨立標籤實際寬度縮排，接在標籤右側。12 個表單正文欄位皆納入檢查，包括此前遺漏的 3 個短句。

0.1.5 修正學校問卷回答與標籤重疊、年齡標籤擠到數字的問題。退出時略過不再需要的畫面還原；保留原生存檔流程。退出延遲實測與剩餘限制見 EXIT-PERFORMANCE.zh-TW.md。

0.1.6 修正 s-0056 尋人啟事：移除年齡與最後現身日期間多餘空行，聯絡提示改為單行，避免碰到人物特徵及聯絡人資料。保留原有資訊及效能、退出修正。

## 0.1.7 正文與名牌

s-0023 便箋正文以紙張的可見內側底部為硬性邊界，避免沿用英文溢出高度。故事名牌依內側寬度縮小過長的人名及身分文字，避免換行與下欄重疊；只調整顯示字級，完整文字與遊戲原始資料保留。量測結果沿用既有顯示快取。

## 0.1.8 主選單標題

主選單標題、歡迎文字與陰影依原有列高量測字級；製作署名限制在版本資訊左側欄寬，避免重疊。字級僅於顯示／量測期間暫時替換並還原，量測結果快取，不修改遊戲文字或資源。

## 0.1.9 人物選單與技能欄位

共用人物選擇按鈕將姓名靠上顯示，按 95 單位內側欄寬及姓名／等級各自的行高縮放，避免姓名壓住技能等級或伸入下一欄。人物資訊欄名改為「項目加成」，並依各欄空間量測。原版 RZ5 的 New Romina 與 Awakened Romina 為同一角色的不同 UI 名稱，中文均統一為「覺醒的蘿蜜娜」。僅調整顯示，不改角色識別碼或存檔。

## 0.1.10 便箋紙張邊界

改以便箋圖片保持比例縮放後的實際繪製底邊、預留 24 單位頁腳間距，取代 s-0023 單篇固定高度。正文以紙張底邊及可捲動範圍中較小者為界，不再沿用英文溢出餘量。紙張物件查找與文字量測沿用快取；不刪減文字或改動原始場景。

## 0.1.11 許可執照

s-0115 將持照人、營業場所與許可內容整合為有標籤的正文，取代空格留位及獨立姓名欄位造成的重疊。完整保留姓名、酒館名稱與條款，正文限制在頁腳備註之前，中文模式隱藏兩條填寫底線；F8 可還原英文欄位與底線。


## 0.1.12 全資訊圖排版檢查

檢查全部 421 個資訊圖版型，在 720p／1080p、一般／易讀字型四組設定量測正文與短欄位。修正中文行距、標題與日期高度、註腳定位、多欄表格及插圖留白；排版結果快取，英文切換還原原有設定。完整方法、視覺複查與例外說明見 FULL-LAYOUT-AUDIT.zh-TW.md。

## 0.1.13 紙張頁面與退出崩潰

修正 s-0065 等將紙張圖片掛在 Page 頁面本身的版型：以圖片按比例繪製後的實際底邊限制正文，保留頁腳留白，不再讓文字落入兩頁間的空隙。s-0065 的兩個正文欄位在 720p／1080p、一般／易讀四組設定都在紙張界線內，英文切換保留原始字串與幾何。

修正隨載入器附帶的 MonoMod.Utils.dll 對此 Unity x86 Mono 的相容性：SetMonoCorlibInternal 原本寫入位移 79，破壞位移 76 的 friend_assembly_names 指標；本機匹配的官方 PDB 確認 corlib_internal 應位於 83。這是退出時 mono_domain_free+0x480 讀取 0x01000000 的原因。修正版不修改遊戲 DLL、Mono DLL 或存檔，也不跳過原生退出／存檔流程。

一般預覽退出及存檔副本的原生儲存退出均回傳 0，無 Crash!!! 記錄；兩次退出存檔都完成，副本 XML 可解析，玩家原存檔 SHA-256 不變。ComputeBuffer 退出警告仍可出現，已證實不是此次存取違規的原因；試驗性 GPU 清理已移除。詳見 page-paper-fix/verification.json 與 exit-crash-fix/verification.json。

相容性修正限定於此套件驗證的 Mono SHA-256：473D59FE1F1A2CBBF37340517CA6F9C6A48330D44DC609E5C3209ADF63792FCF。安裝器會拒絕其他 Mono 版本；遊戲更新後請重新驗證。MonoMod 原檔、修補腳本與授權皆保留。


## 0.1.14 插圖留白與經驗池用語

s-0198 恢復翻譯時遺漏的插圖留白，並按實際中文字型行高計算正文起點；避免低解析度的字型量測及縮字壓縮留白。時代經驗池改為「剩餘 XX 經驗」，支援負數；不改動年代、角色或劇情。保留 0.1.13 的退出相容性修正。
