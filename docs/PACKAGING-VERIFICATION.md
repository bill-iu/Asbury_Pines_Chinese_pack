# 簡易安裝包驗證

封裝版本：`0.1.14-pack.2`；插件版本：`0.1.14`。驗證日期：2026-10-07。

本次重新封裝的插件、全部詞庫及載入器，已逐檔比對目前安裝內容的 SHA-256，確認一致。插件顯示及翻譯邏輯沒有變動。原有遊戲內測試範圍請見 `RELEASE-VERIFICATION.md`。

本次驗證通過：

- 原有 119 個詞庫回歸案例及 15 個警察表單來源變體。
- 原有安裝器的首次安裝、檔案鎖定失敗後回復、修改檔案拒絕更新與保留修改檔案的卸載。
- 所有 PowerShell 腳本語法檢查；中文腳本使用 UTF-8 BOM 供 Windows PowerShell 5.1 讀取。
- EXE 內嵌 ZIP 校驗及完整解壓，每個檔案逐一核對 `SHA256.json`。
- 實際執行 EXE 的首次安裝及更新，檢查 98 個安裝檔案的雜湊。
- 含中文、空格及括號的遊戲和解壓路徑。
- 只檢查模式不寫入遊戲；不符的 Mono 版本及無法辨認的同名載入器會停止安裝。
- 自行修改的翻譯拒絕更新並在卸載時保留。
- 有其他插件時拒絕完整卸載；只卸載繁中插件會保留共用載入器和其他插件。
- 永久啟用及停用設定，完整卸載及遊戲程式／Mono 原檔保持不變。
- 發佈包內容排除遊戲程式、素材、存檔、玩家設定、開發診斷及測試用遊戲檔。

安裝測試使用遊戲版本檢查所需的檔案副本和不可執行的遊戲入口占位檔，沒有啟動測試遊戲或改動現有安裝。副本留在忽略的 `test-work/`，不會上傳或封裝。本次沒有重新窮舉遊戲進度，也沒有自動點擊檢查圖形介面；EXE 的解壓及底層操作透過同一安裝入口實際驗證。

可重跑驗證：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Pack.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-Pack.ps1 -GameRoot '已安裝的相容遊戲資料夾'
```

已有同名發佈檔時，重建會停止，避免意外取代已發佈檔。測試會建立隔離資料夾，不會將補丁安裝到傳入的原有遊戲資料夾。

本次 pack.2 另驗證繁中→簡中→繁中安裝互換。編譯詞庫測試需 PowerShell 7 (pwsh.exe)；正式安裝器使用內建 Windows PowerShell，無需 PowerShell 7。
