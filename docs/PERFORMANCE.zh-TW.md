# 0.1.1 效能改善實測

在這台電腦、相同1280×720設定下比較。英文基準保留BepInEx與相同的暫時量測探針，移除漢化DLL；不是完全無載入器的原版測試。基準列為兩次平均，舊版與交付版各列一輪完整記錄；移除最後的場景掃描前，亦另測試兩輪優化版本，原始JSON保存在開發目錄 performance。毫秒數包含畫面更新等待，因此受幀時間與GC波動影響。

## 改動

- 場景載入不再掃描並重設所有隱藏文字；透過文字啟用事件，集中在當幀最後的可見狀態設定字型。
- 每個文字元件快取繪製結果；來源文字、翻譯、字型、尺寸、行距或可捲動範圍改變才重新計算。
- 內嵌3,044組經驗證的故事排版結果及4組插圖留白結果。背景讀取並核對系統字型雜湊；尺寸、字型或譯文不符時回到即時計算。
- 停用插件時不載入詞庫。測試探針不隨正式插件安裝。

六個故事的漢化排版處理由 276.8 毫秒降到 16.9 毫秒。仍有動態中文字型首次生成字形的成本，個別首次畫面不保證與英文完全等速；工作分頁等項目的殘餘差異已完整列出，沒有以單一較快項目代表所有情境。

功能驗證：114項詞庫測試；預先量測涵蓋421個故事版型、720p／1080p一般與易讀模式；交付版再驗720p兩模式，新增長文溢出為0。保留中英切換、版面修正與存檔。
