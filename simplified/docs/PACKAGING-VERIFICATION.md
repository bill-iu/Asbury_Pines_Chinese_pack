# 简体中文版本验证

版本 `0.1.14-pack.2`，验证日期 2026-10-07。

- 4,237 条词库记录及 47 条动态规则的输出文字来自 OpenCC `tw2s` 转换。
- 逐条验证英文来源键及正则表达式未改变；富文本标记、替换占位符和换行结构保持一致。
- 简中源代码转换后重新编译，包含动态通知、资源提示及其他程序内显示文字。
- 逐条验证编译词库输出，以及原有 119 个动态、富文本、未知文字和识别码回归案例。
- 不包含繁中版预先量测的排版快取，使用原有即时量测及执行期缓存。
- EXE 解压及 SHA-256、中文及空格路径、安装／更新、版本拒绝、已有文件保护、语言配置及卸载通过隔离副本测试。
- 繁中→简中→繁中互换使用同一份安装清单，通过副本测试；其他插件及原始游戏文件保留。

以上验证不表示已重新完成全部游戏内视觉检查。繁中版的历史排版检查不能视为简中版的独立测量结果。测试用游戏副本位于忽略的 `test-work/`，不会打包或上传。
